# moranricardo/cli

Herramienta de línea de comandos (CLI) escrita en Go, optimizada para ejecutarse de forma nativa en dispositivos de baja gama como el **Moto E6 (Android 9 / ARM32)** a través de **Termux**.

## ⚙️ Especificaciones Técnicas
- **Entorno:** Moto E6 (Android 9) / ARM32
- **Consola:** Termux (Desplazador y consola local)
- **Lenguaje:** Go 1.27 (`CGO_ENABLED=0`, `-trimpath`)
- **Orquestador:** Dependabot Lite Diamond (`DEPENDABOT_LOCAL_RUN=1`)
