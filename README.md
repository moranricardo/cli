# moranricardo/cli

Repositorio de práctica y orquestador nativo para Moto E6 (Android 9 / ARM32).

## 🛠️ Especificaciones Técnicas y Entorno
- **Arquitectura:** ARM32 / Sin contenedores Docker
- **Go Version:** 1.27 Stable (`CGO_ENABLED=0`)
- **Orquestador:** Dependabot Lite Diamond (`DEPENDABOT_LOCAL_RUN=1`)
